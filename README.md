# Snake

Classic snake in plain HTML, CSS and JavaScript (Canvas). Game loop, collision detection, score and a best score saved in the browser.

**Controls:** arrow keys or WASD, or the on-screen pad on mobile.

**Run it:** open `index.html` in a browser.

**Files:** `index.html` (page), `style.css` (look), `script.js` (game logic).

---

# Змейка

Классическая змейка на чистых HTML, CSS и JavaScript (Canvas). Игровой цикл, проверка столкновений, счёт и рекорд, который сохраняется в браузере.

**Управление:** стрелки или WASD, на телефоне кнопки на экране.

**Запуск:** откройте `index.html` в браузере.
